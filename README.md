# Okey Masası · Troçki Studio

Üç bilgisayar rakibiyle klasik Okey. Telefon ve bilgisayarda tarayıcıdan oynanır. Ana ekrana eklenebilir. İlk çevrimiçi yükleme tamamlandıktan sonra çevrimdışı açılabilir.

## GitHub Pages

Dosyaları deponun `main` dalının köküne ekleyin. Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

iPhone’da Safari → Paylaş → Ana Ekrana Ekle. Android’de Chrome → Uygulamayı yükle.

## Yerel geliştirme

Bu dizinde `python3 -m http.server 8000` çalıştırıp `http://localhost:8000` adresini açın. Çevrimdışı önbellekteki dosyalar değiştiğinde `sw.js` içindeki önbellek sürümünü artırın.
